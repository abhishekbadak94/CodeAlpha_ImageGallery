# 📸 CodeAlpha Image Gallery

A responsive image gallery built using HTML, CSS, and JavaScript as part of my CodeAlpha Frontend Development Internship.

## 🚀 Features

- Responsive image gallery
- Hover zoom effect
- Smooth transitions
- Lightbox image viewer
- Next and Previous navigation
- Close button
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
